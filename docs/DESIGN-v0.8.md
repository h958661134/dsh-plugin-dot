# Dot v0.8 会话管理：理想设计与这一版的实现

> 原则：**设计往大处想，实现往稳处做。** 凡是会在别的会话里「替你开口」、新开会话花 token、或改动侧栏的动作，都必须由你点一下才执行。Dot 只能起草，不能自己发出。

## 一、现在到哪了（v0.7.1）

Dot 已经能做到这些：

- **看**：会话总览里能看到每个会话的状态、当前步骤、待办进度、改了哪些文件、后台任务、上下文用量，还能看到它是不是卡住了。
- **盯**：会话结束或出错时通知你，并附一句总结。
- **停**：停掉某个会话。
- **记**：把某个会话记为一件事务。
- **巡检**：会话出错没人管时提建议。

还缺的是：Dot 只能**旁观**会话，不能**调度**会话。

- 它不知道三天前那个会话里聊过什么。
- 它不能替你给另一个会话补一句话。
- 它不能新开一个会话去干活，再盯着那个会话。
- 会话越积越多，侧栏越来越乱，它也帮不上忙。

## 二、理想形态：Dot 是你的「会话调度台」

把每个会话当成一个**在干活的同事**，Dot 是你的工作台。

| 能力 | 理想中的样子 | 用到的 DSH 能力 |
|---|---|---|
| **回忆** | 「上周改登录页的那个会话在哪？」Dot 全文搜索所有会话，告诉你是哪一个、聊到哪一句，点一下就能打开 | `sessionQuery.searchSessions`（SQLite 全文索引） |
| **读档** | 「那几个会话各做到哪了？」Dot 读各会话最近几轮的问答，给你一段汇总，不用你挨个点开 | `sessionQuery.filterEvents`（按类型取 `user/message`、`assistant/message`） |
| **转告** | 「让写报告那个会话把图表也补上。」Dot 起草一句话，你点「发送」，它送进那个会话 | 定时服务 `after` 投递到目标会话（已用于 Dot 自己，路子验证过） |
| **派活** | 「开个新会话把这个仓库的测试补齐，做完告诉我。」Dot 写好任务说明，你点「开始」，它新开会话并自动盯着，同时记一件「已委派」事务 | 定时服务 `new_once`：创建时就预留了新会话的 id，所以能先盯上 |
| **交接** | 某个会话的上下文快满了，Dot 提醒你，并能读一遍这个会话、写出交接说明，再派给一个新会话接着做 | `tokenMeter.contextPressure` + 读档 + 派活 |
| **收纳** | 「有 6 个会话一周没动了，收起来？」点一下归档，随时能撤销 | `workspaceRegistry.archiveSession / unarchiveSession` |
| **事务和会话双向关联** | 事务记着是哪个会话在做；会话结束，Dot 问你要不要把事务标完成；事务卡上能看到那个会话现在的状态 | `Task.sessionId` |
| **项目视角** | 按工作目录把会话分组：这个项目今天跑了几个会话、各做了什么 | `SessionHeader.cwd` |
| **周报** | 「这周各会话做了什么」：按天、按项目汇总 | `filterSessions` 的 `created-at` 过滤 + 读档 |
| **分叉试错** | 「从第 5 轮分出去，换个方案试试」 | 会话控制器的 `fork`。目前只开放给客户端 RPC，插件拿不到，先不做 |
| **团队视图** | 多个会话组成一个团队时，显示任务依赖图 | `agentTeams`。等官方稳定后再做 |

### 安全边界（理想形态里也不放开）

| 动作 | 规矩 |
|---|---|
| 读其他会话 | 只读。遵守 `watchOthers` 开关：你关掉监控，Dot 就不读。不读 Dot 自己派出的子任务以外的子代理 |
| 转告 | 只能起草，你点「发送」才送出。送进去的话带上「（Dot 代你转告）」，那个会话知道这话不是你亲手打的。不能转告给 Dot 自己的会话或子代理 |
| 派活 | 只能起草，你点「开始」才新开会话。新会话用 DSH 默认预设，不带 Dot 的规则闸门，审批照常由 DSH 管 |
| 归档 | 只能起草，你点了才归档。正在跑的会话 DSH 会拒绝归档，Dot 不强停。随时能撤销 |
| 停止、删除 | 停止仍然只在总览里由你点。删除会话不做 |

## 三、这一版实现什么（v0.8）

挑「只读的」和「起草后要你点头的」两类，DSH 的接口都在源码里确认过：

1. **`dot_sessions` 工具**
   - `list`：所有其他会话的一行现状。
   - `search`：全文搜索会话，返回会话、命中片段和打开链接。
   - `read`：读一个会话最近几轮的问答，每段截断，最多 6 轮。
2. **转告**：`dot_sessions relay` 只生成一张建议卡「转告「X」：……」，你点「发送」才投递。
3. **派活**：`dot_sessions dispatch` 只生成一张建议卡，你点「开始」后会做三件事：
   - 新开一个会话（可以指定工作目录）。
   - 自动盯着它。
   - 记一件关联了这个会话的「已委派」事务。
4. **收纳**：巡检每天检查一次。三天以上没有新一轮对话的会话，不算正在跑、置顶、盯着和 Dot 自己的会话，凑满 3 个就提议「收起来」。你点了才归档，之后收件箱里有一张「撤销」卡。
5. **事务和会话关联**：
   - 事务新增 `sessionId` 字段。总览里的「记为事务」和派活都会填上。
   - 关联的会话跑完后，Dot 会建议把事务标成完成。
   - `dot_tasks list` 会显示关联会话的现状。
6. **上下文快满提醒**：正在跑的会话上下文用到 85% 以上时，Dot 提议让它「读一遍、写交接说明、派给新会话」。

不做：分叉、团队视图、项目分组界面、周报（`read` 和 `list` 已经能让 Dot 口头汇总，界面留到下一版）。

## 四、实现结果（0.8.0）

代码：
- `lib/sessions.js`（新）：`dot_sessions` 工具、`findStale`、`turnsFromEvents`、无索引时的扫描搜索。
- `lib/host.js`：执行建议卡里的 `relay`、`dispatch`、`archive`、`unarchive`、`complete`。
- `lib/suggest.js`：巡检多了三条：关联会话跑完、上下文快满、收纳。
- `lib/hub.js`：`prewatch`，派活的会话还没跑起来就先盯上；`configure`，把 `watchOthers` 开关和「哪些是 Dot 会话」告诉工具。
- 事务新增 `linkedSession` 字段。

测试：新增 `tests/v8.test.mjs`，共 121 个测试全部通过。

隔离 DSH 实测（真模型）：

| 功能 | 结果 |
|---|---|
| list + read | Dot 汇报了三个会话各做到哪，并把其中一个和事务 t7 对上 |
| search | 这个 DSH 的全文索引是关的（`openAt: never`）。第一次实测报错，加了逐个扫描的退路后，搜「目录」命中两个会话 |
| 输出格式 | 第一次实测报 `content.some is not a function`，是工具输出没包成内容块数组。已修，并加了回归测试 |
| 转告 | Dot 起草后卡片出现在对话事务卡和「今天」页。点「发送」后，目标会话收到「（Dot 代你转告）只回复一个字「收」」，回了「收」。那个会话当时没加载，走的是定时服务 |
| 派活 | 点「开始」后新会话开工，Dot 一直盯着。跑完的通知里带着回答，巡检随即提议把「已委派：解释幂等性」标完成，点了之后事务状态变成 done |
| 归档、撤销 | 点「收起来」后会话从侧栏消失；收件箱出现「撤销」卡，点了放回侧栏 |

没实测：
- 上下文快满提醒：隔离 DSH 里没有快满的会话。
- 三天没动自动提议收纳：隔离 DSH 里的会话都不到三天。

这两条只有单元测试。

观察：
- 派活新开的会话标题是「Dot 派活：……」（DSH 用定时任务标题做会话名），放在侧栏「未分组」。指定 `cwd` 时会进对应工作区。

下一步候选：
- 会话总览加搜索框和「转告…」输入框。
- 按工作目录分组的项目视图。
- 周报。

## 五、会话总览界面（0.8.1）

改动：
- **搜索框**：在总览顶部，走新接口 `POST /sessions/search`，和 `dot_sessions search` 共用 `searchUserSessions`。
  - 有全文索引时用索引，没开就逐个扫描最近 30 天的会话。
  - 只返回用户自己的会话。
  - 结果显示会话名、多久以前、命中的那句话，点一下打开。
- **「转告…」**：每张卡上都有，点开是一行输入框。
  - 这是你亲手写、亲手点发送的，所以直接送出，不再经过建议卡。
  - 正在跑的会话会在当前这一步之后看到；没加载的会话由定时服务唤起。
- **「归档」**：只出现在已结束的卡上。点了就归档，Dot 收件箱里出现「撤销」卡；正在跑的会话 Host 会拒绝。
- 「移除」改为只从总览里拿掉，侧栏不变，按钮提示写明了。

测试：
- `ui.test.mjs` 新增一条：在搜索框里搜，检查结果渲染；打开转告框发送，检查请求；正在跑的卡没有「归档」。
- `v8.test.mjs` 新增一条：三个接口的行为，包括空话不发、正在跑的不归档。
- 共 123 个测试全部通过。

隔离 DSH 实测：
- 搜「幂等」命中派活开的那个会话，Dot 自己的会话没有出现在结果里。
- 用「转告…」发了一句话，提示「已转告「……」，几秒后送到」，那个会话随即开始跑。
- 确认了输入框跟着所点的卡走：用脚本点某张卡的「转告…」，输入框只出现在那张卡里。
