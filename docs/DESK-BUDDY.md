# 桌宠设计

> 状态：已实现（未发布）。实测截图见 [images/buddy.png](images/buddy.png)。已确认的选择：**B 任务栏居民**、**不做成长系统（装扮一开始全部可选）**、**保留方块小精灵并做得更可爱**；这一版做：喂食、专注陪伴、早晚问候、包裹 / 信封代替角标、**键盘输入和工作时长统计**。

## 一句话

小精灵以前是一个会变色、会眨眼的角标。现在 Dot 住在你的任务栏上，会走、会睡、会吃，还陪你一起敲键盘。
**它的每个动作都对应一件管理上的事**：举着包裹，表示有事需要你；在吃星星，表示你刚勾掉一件待办；戴着耳机坐着，表示你们在专注；揉眼睛伸懒腰，表示你已经连续干了很久。
管理功能没有新增入口，只是改用身体语言来表达。

## 原则

1. **动作即状态**：不为可爱而加动作。每个姿态都对应一个管理信号，瞟一眼就知道该不该理它。
2. **不打卡、不计分**：没有等级、亲密度、连续天数，也没有饥饿、生病、死亡。它是陪你干活的同事，不是要你每天来喂的电子宠物；待办本身已经够有压力了。
3. **不打扰是第一美德**：全屏、演示、专注时安静；你离开电脑它就睡觉；夜里不在屏幕上乱跑。
4. **不调模型**：走路、睡觉、成长、专注、问候、统计全在本地算。
5. **管理逻辑全在 Host**：精灵只负责画和动。专注、问候、休息、统计汇总都在 `lib/petlife.js` 里算，网页小精灵以后也能用同一份数据。

## 形象：还是那个方块小精灵，更可爱

保留圆角方块身体和两只竖条眼睛，这是辨识度。在此基础上加：

| 部件 | 说明 |
|---|---|
| 小脚 | 两个小椭圆，走路时交替抬起；站着时偶尔踮一下 |
| 嘴 | 平时是小小的 ω；吃东西时张合；惊讶时变成 o |
| 腮红 | 被摸、吃到星星时出现 |
| 影子 | 脚下一小块半透明椭圆，跳起来时缩小，能看出高度 |
| 头顶呆毛 | 一根小弧线，走路时跟着晃，开心时竖起来 |
| 装扮层 | 围巾、叶子、帽子、耳机、蝴蝶结、皇冠，全部矢量绘制，一开始就都能选 |

**表情**（眼睛和嘴的组合）：

| 表情 | 眼睛 | 嘴 | 什么时候 |
|---|---|---|---|
| 平常 | 竖条 | ω | 空闲 |
| 开心 | ^ ^ | 张开 | 被摸、吃星星 |
| 专心 | 竖条，左右扫 | 抿嘴 | 有会话在跑 |
| 担心 | 竖条，一滴汗 | ~ | 包裹多于 3 个、有逾期 |
| 惊讶 | 圆点 | o | 被甩出去、新卡片到来 |
| 晕 | @ @ | ~ | 落地后 1 秒 |
| 困 | 半闭 | 打哈欠 | 连续工作很久、夜里 |
| 睡着 | 一条线 | 小 o，冒 z | 你离开电脑 |
| 眨眼 | 一边闭 | ω | 偶尔对你眨一下 |

**小动作**（空闲时随机，间隔 8～30 秒，全屏或专注时不做）：

- 眼睛跟着鼠标看：鼠标在附近时，眼珠朝它偏。
- 伸懒腰、打哈欠、原地坐下、歪头、跳一下。
- 走路时偶尔绊一下，然后若无其事地站起来。
- 你离开后回来（系统空闲超过 5 分钟后又有输入）：它醒来，朝你挥挥手。
- 跟着打字：你连续快速打字时，它面前出现一个小键盘，跟着一起敲。

## 待在哪里

- **默认住在任务栏上**：站在工作区底边。空闲时左右溜达，范围不超过出生点左右 240 像素。
- **拖到左右边缘**：和以前一样吸附、半隐藏。想让它安静不走，就把它塞到边上。
- **拖到半空松手**：它会掉下来落在任务栏上。甩一下会被扔出去，撞到屏幕边会弹回，落地后晕一下。
- **安静的时候**：全屏应用或演示模式下（系统通知状态为忙碌、全屏、演示），它不走动、不冒气泡，有事只举包裹。

## 互动

| 动作 | 结果 |
|---|---|
| 单击 | 打开面板（和现在一样） |
| 双击 | 打开 Dot 会话 |
| 鼠标在它身上来回蹭 | 摸摸：眯眼、腮红、冒爱心 |
| 把文字或文件拖到它身上 | 它「吃进去」，记成今天的一件待办 |
| 面板里待办上的 🎧 | 开始 25 分钟专注 |
| 右键 | 打开 Dot、会话总览、今日简报、专注、换装、今日统计、安静模式、暂停 |

## 和管理功能怎么融在一起

### 包裹和信封代替角标

| 它手里拿着 | 意思 |
|---|---|
| 包裹，写着数字 | 有 N 张「需要你」的卡（审批、提问、逾期、快到期）。有急事时包裹变红，它跳着举高 |
| 信封 ✉ | 有会话跑完了，给你送信。点它直接打开面板里那张卡 |
| 什么也没拿 | 没事 |

### 喂食：勾掉待办就是喂它

勾掉一件待办，它就吃到一颗星星，开心地嚼一嚼，是对「做完了」的一个小小确认。精灵面板、Dot 窗口、`/done`、对话里完成都算，周期待办每次都算，放弃的不算。不记分，不累计。

### 专注陪伴

1. 在面板的待办上点 🎧：它戴上耳机坐下，身边亮起一圈进度环，默认 25 分钟。
2. 这段时间里它不走动、不冒气泡、不晃。有急事只在包裹上亮。
3. 到点时它摘下耳机，出一张卡：「专注 25 分钟到了：『写周报』」，按钮是 **勾掉**、**再来 25 分钟**、**先这样**。
4. 中途停下就停下，不算失败，也不记录。

### 早晚问候

- **早上**：5 点以后第一次看到你有输入时，它说「早！今天 3 件待办，先办『交周报』？」，点一下打开面板。
- **傍晚**：18 点以后，如果今天还有没勾掉的，出一张卡：「今天勾掉了 4 件、专注 2 轮、工作 6 小时 10 分；还剩 2 件」，按钮是 **剩下的推到明天**（走现有的推迟逻辑，可撤销）和 **知道了**。

两种问候每天各出现一次。

### 键盘输入和工作时长

**隐私边界**（写死在代码里）：
- 只计**按键次数**，不记按了哪个键，不记任何内容，不区分窗口和程序。
- 计数在精灵进程的内存里累加，每分钟把「这一分钟按了几下、有没有在用电脑」交给 Host。Host 只存按小时汇总的数字。
- **按键计数默认关闭**，在右键菜单「今日统计」里开启。开启后，面板顶部有一个小 ⌨ 标记，表示正在计数。**工作时长**不需要键盘钩子（用系统的「最后一次输入时间」），默认开启。
- 数据只在本机 `state.json`，保留 30 天。

**怎么算**：

| 指标 | 算法 |
|---|---|
| 工作时长 | 每分钟检查系统最后一次输入时间。这一分钟内有键盘或鼠标输入，就算 1 分钟在工作 |
| 连续工作 | 中间没有超过 5 分钟的空闲，就算连续 |
| 按键次数 | 低级键盘钩子只把计数 +1，不读键值 |
| 打字节奏 | 最近 10 秒的按键数，用于「跟着一起敲」的动画 |

**和管理怎么接**：
- **连续工作 90 分钟**：它开始揉眼睛、打哈欠，冒一句「已经连续干了 1 个半小时，起来走走？」，按钮是「休息 5 分钟」和「再干会儿」。点「休息」后它也去睡 5 分钟，到点叫醒你。一天最多提醒 3 次；专注中不提醒，专注结束后再说。
- **傍晚收尾卡**和**今日简报**里加一行：「工作 6 小时 10 分，敲了 1.2 万下，勾掉 5 件」。
- **右键「今日统计」**：一张小卡片，内容有今天的工作时长、按键次数、勾掉几件、专注几轮，以及按小时的迷你柱状图，按小时显示一天里什么时候最忙。
- **专注**期间的工作时长单独记，结束卡上显示「这 25 分钟里有 23 分钟在敲」。

## 换装

右键「换装」：不戴、小围巾、头顶小叶子、鸭舌帽、耳机、蝴蝶结、小皇冠，一开始全部可选，随时换。专注时会自动戴上耳机，结束后换回原来的装扮。

## 数据

`state.json` 新增 `prefs.life`，旧数据不用迁移：

| 字段 | 含义 |
|---|---|
| `outfit` | 当前装扮 |
| `focus` | 进行中的专注 `{ taskId, title, startedAt, until, minutes }` |
| `today` | `{ day, done, focus }` |
| `greetedDay`, `eveningDay` | 早晚问候出现过的日期 |
| `breaks` | `{ day, count }` 今天提醒休息了几次 |
| `lastFed` | 最近一次勾掉待办的时间，精灵据此播放吃星星 |
| `activity` | `{ keys: boolean, hours: { "2026-11-12T14": { active, keys } } }`，按小时汇总，保留 30 天 |

### 接口

`/status?desk=1` 的 `desk` 里新增：`life`（装扮、专注、`lastFed`）、`stats`（今天的工作时长、按键数、连续工作分钟数）、`greeting`。早晚问候、专注到点、休息提醒放进 `cards`。

`POST /api/dsh-plugin-dot/pet`（精灵写接口白名单加上 `/pet`）：

| action | 参数 | 说明 |
|---|---|---|
| `focus` / `focus-stop` | `id`, `minutes?` | 开始或停止专注（5～90 分钟） |
| `outfit` | `id` | 换装 |
| `evening` | `op`: `tomorrow` / `dismiss` | 傍晚收尾卡 |
| `greeted` | | 早上的问候看过了 |
| `activity` | `minutes: [{ at, active, keys }]` | 精灵每分钟上报一次 |
| `keys` | `on` | 开关按键计数 |
| `break` | `op`: `rest` / `later` | 休息提醒 |

## 技术要点

- **全部矢量绘制**：用 WPF 的 Path、Ellipse，跟随系统缩放；不用 GIF 或位图。
- **动画**：一个 30fps 的 DispatcherTimer 驱动走路、重力和粒子；表情切换用 WPF 自带动画。空闲且没有动作时降到 4fps，省电。
- **窗口**：从 320×96 改为大约 360×150，给跳跃、装扮、粒子留空间。透明部分仍然点击穿透。
- **工作时长**：`GetLastInputInfo`，不需要钩子。
- **按键计数**：`SetWindowsHookEx(WH_KEYBOARD_LL)`，回调里只做 `count++`，不读 `vkCode`。只在开启时才安装钩子，关闭时立即卸载。部分杀毒软件可能对键盘钩子报警，这也是它默认关闭的原因之一。
- **全屏检测**：`SHQueryUserNotificationState`。
- **测试**：`petlife.js` 的纯计算全部有单元测试。精灵端靠在隔离 DSH 上实测，并截图核对各个姿态。

## 不做的事

- 不做等级、亲密度、连续天数、成就，不让它变成打卡工具。
- 不做饥饿、生病、死亡，不让你对一个像素生物内疚。
- 不在别的窗口上爬，不挡光标，不追着鼠标跑。
- 不记录按了什么键、在哪个程序里，不截屏，不联网。
- 工作时长和按键数不做排行，也不做「今天不够努力」这类评价，只陈述数字。

## 分步实现

1. Host：`lib/petlife.js`（专注、问候、休息、统计汇总、装扮）和 `/pet` 接口，并接进 `closeTasks` 和 `deskView`。
2. 精灵：新形象（脚、嘴、腮红、影子、呆毛、装扮层）和表情系统。
3. 精灵：任务栏行走、重力、甩出去、睡觉、全屏安静。
4. 精灵：包裹 / 信封、吃星星、专注环、早晚问候、休息提醒。
5. 精灵：工作时长和按键计数（开关、⌨ 标记、今日统计卡片）。
6. 测试、隔离 DSH 实测截图、README / CHANGELOG。
