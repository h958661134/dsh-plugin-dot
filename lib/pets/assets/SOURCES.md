# 人物试作素材

本文记录 v1 原始人物稿。当前使用的卡通 v2 图片、参考来源与提示词见 [CARTOON-SOURCES.md](CARTOON-SOURCES.md)。其中鲸鱼娘 v2 是 DeepSeek 社区形象的参考衍生素材，采用单独标注的 CC BY-NC-SA 4.0 许可。

由内置 image_gen 工具生成，2026-11-14。人物均为原创成年角色。PNG 保留原始透明通道；运行时按 3 列 × 2 行裁取显示，不在安装时生成图片，也不请求外部图片地址。

每张图集六格依次是站立、招手、闭眼、桌边静止、左手抬起、右手抬起。最后一张图额外修正了右下角的左右手对应关系，并清理了透明通道中的背景残留。最终文件为 whale-maiden-v1.png、young-man-v1.png、young-woman-v1.png，均位于本目录。
