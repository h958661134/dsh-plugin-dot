# 精灵图鉴与替换接口

`catalog.json` 是形象和小动作的共同来源。桌面 WPF、网页 SVG、Dot 窗口的角色选择都读这份图鉴。运行时不需要生成图片，也不调用模型。

## 现在能换什么

- 小点、棉花兔、糯米猫三种形象；名字、颜色、装扮和待办各自保存。
- 桌面右键 →「换个小伙伴」；网页精灵面板底部；Dot 窗口 → 规则 → 小精灵。
- 保持角色的 `id` 不变，更新配置就是更新这个角色；添加新 `id` 就会自动成为一个可选角色。
- 保存的位置是 `prefs.pet.character`。暂时不认识的 ID 显示默认小点，但保留原 ID，重新加入图鉴后能恢复。
- 图鉴格式错误时 Host 会记录原因，并退回最小的小点图鉴；不会执行图鉴里的代码。

## 形象契约 v1

当前渲染器为 `dot-vector-v1`，使用 56 × 66 的共同身体坐标。身体在 `(4,10)`，大小 `48 × 46`；眼睛、嘴、双手和装扮的位置固定。舞台为头顶、耳朵、尾巴和跳跃留有空间。

| 字段 | 用途 |
| --- | --- |
| `id` | 稳定标识，小写字母开头，只用字母、数字、短横线，最长 40 字符 |
| `name` / `description` | 选择器显示的名字和一句描述 |
| `renderer` | 当前必须是 `dot-vector-v1`；未来其他渲染方式由独立适配器实现 |
| `color` | 默认配色：blue / green / orange / purple / pink / gray；用户选过的颜色优先 |
| `radius` | 身体圆角，0～28 |
| `ahoge` | 是否显示呆毛 |
| `back` | 身体后面的矢量图层，适合耳朵、尾巴 |
| `front` | 身体前、表情后的图层，适合花纹、肚皮 |

每个图层最多 24 条路径。路径使用 SVG/WPF 共同支持的 `M L H V C S Q T A Z` 命令（也支持小写），不含指数写法。建议所有笔画位于 `x = -8～64, y = -18～66` 范围内。没有图片 URL、XAML、HTML 或可执行脚本。

```json
{
  "id": "little-bear",
  "name": "小熊团",
  "description": "圆耳朵的小伙伴。",
  "renderer": "dot-vector-v1",
  "color": "orange",
  "radius": 23,
  "ahoge": false,
  "back": [
    { "d": "M5 13 A8 8 0 1 1 21 13 Z M35 13 A8 8 0 1 1 51 13 Z", "fill": "body" }
  ],
  "front": []
}
```

路径的 `fill` / `stroke` 可用 `body`（主色）、`light`（高光）、`face`（白色）、`none` 或六位十六进制颜色。描边 `width` 在 0～6 之间。动态配色使用 `body` / `light`，角色专属的花纹使用固定颜色。

增加形象时，把对象加入 `characters` 数组。更改后重启隔离的 DSH 或预览服务器，再验证所有动作和装扮。默认 `dot` 不能删除。至少检查长耳朵与帽子、耳机、包裹、贴边状态是否重叠或被裁切。

**当前已经实现的是共用身体坐标的矢量形象。** PNG、动画精灵图、完全不同的骨架尚未实现。`renderer` 是后续替换绘制方式的入口：新增适配器时保留行为、状态、通知、角色 ID 和手动互动接口，只替换绘制部分；在适配器完成前，不能仅改 `renderer` 字符串就加载图片。

## 动作契约 v1

`gestures` 中的动作会自动出现在「陪我玩一会儿」菜单。已有挥手、抱抱、夸夸它、捉迷藏、摇摆、伸懒腰六组。持续时间 500～4000ms，不排队，不叠加。

`frames` 的 `at` 从 0 到 1 严格递增。每帧省略的值回到中立值，**不继承上一帧**：

| 数值 | 含义 | 中立值 |
| --- | --- | --- |
| `tilt` / `lift` | 身体旋转角度 / 垂直位移（负值向上） | 0 |
| `sx` / `sy` | 身体横向 / 纵向缩放 | 1 |
| `lx` / `ly` / `la` | 左手位移与旋转 | 0 |
| `rx` / `ry` / `ra` | 右手位移与旋转 | 0 |

首尾必须全部回到中立值。缩放在 0.7～1.3 之间，其他幅度在 -60～60 之间；相邻帧使用 smoothstep 插值，与帧率无关。

`eyes`、`mouth`、`cheeks` 控制表情；`particle` 是 heart / star / note / none；可选的 `revealAt` 在动作后段切换为眨眼微笑，用于捉迷藏揭晓。

忙碌、待确认、急事、专注、休息、拖动时不会启动玩耍动作。桌面全屏或安静模式也会阻止动作；新状态到来时立即退出互动并复位。自动动作间隔较长，手动动作有冷却，不累计亲密度、等级或饥饿值。「少动一点」和系统减少动画偏好会将主动互动变成短暂表情回应，不发粒子。

## 验证和维护

```bash
npm test
node scripts/preview-pet.mjs
```

打开 `http://127.0.0.1:4174` 查看三个真实 SVG 角色。点击小动作同时比较；右下角是实际网页精灵组件，支持摸摸、换角色、减少动作。所有数据是演示数据，不会接入日常 DSH。

桌面适配器在 `../desktop/pet-art.ps1`，浏览器适配器在 `../pet-avatar.js`，校验与插值参考在 `../petart.js`。Windows 开发时，将 `DOT_PET_ART_SHOTS` 指向已有的隔离输出目录，再用演示服务器作为 `StatusUrl` 启动测试精灵，会导出三种角色 × 六个动作 × 六个姿态的图片，并验证状态优先级、减少动作、结束复位和未知渲染器回退。它绘制精灵自身，不截取桌面，结束后自动退出；状态文件必须使用隔离路径。
